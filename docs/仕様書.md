**対象ユーザー:** 中学1年生

## 1. プロダクト概要

テスタンは、中学生が定期テスト前に短時間で復習できる学習サポートWebアプリである。

現在のMVPでは、中学1年生の1学期中間テスト範囲（4月から6月）に絞り、国語・数学・英語・理科・社会の5科目に対応する。

### 目的

- 定期テスト前に、5科目を横断して基礎確認できる状態を作る
- 問題演習、解説確認、間違い直しの流れを簡単にする
- 回答履歴から正答率と弱点を見える化する

### 現在の対応範囲

| 項目 | 内容 |
|---|---|
| 学年 | 中学1年生 |
| テスト範囲 | 1学期中間テスト範囲（4月から6月） |
| 科目 | 国語・数学・英語・理科・社会 |
| 問題数 | 5科目合計600問（4択300問 + 短答式300問） |
| 出題形式 | 4択モード、短答式モード（5教科） |
| 1回の出題数 | 最大10問 |

DB設計上は `grade` と `exam_term` を持たせており、今後は中1期末、中2、中3の範囲を追加できる。

## 3. 機能要件

### 認証

| ID | 機能 | 内容 |
|---|---|---|
| AUTH-01 | メール登録 | メールアドレスとパスワードで登録する |
| AUTH-02 | メールログイン | メールアドレスとパスワードでログインする |
| AUTH-03 | Googleログイン | Supabase OAuth経由でGoogleログインする |
| AUTH-04 | ログアウト | セッションを破棄してログイン前画面へ戻る |
| AUTH-05 | 認証ガード | 未ログイン時は保護ページに入れない |
| AUTH-06 | ログイン済み制御 | ログイン済みで認証ページに入った場合はダッシュボードへ送る |

### 学習・クイズ

| ID | 機能 | 内容 |
|---|---|---|
| QUIZ-01 | 科目一覧 | 5科目を表示する |
| QUIZ-02 | 学年選択 | 科目詳細で学年を選択する。現時点では中1が主対象 |
| QUIZ-03 | 通常クイズ | 科目・学年に紐づく問題から最大10問をランダム出題する |
| QUIZ-04 | 出題形式選択 | 科目詳細で4択モードと短答式モードを分けて開始する |
| QUIZ-05 | 4択回答 | AからDの選択肢で回答する |
| QUIZ-06 | 短答式回答 | 5教科で入力欄に答えを入力して回答する。実テスト型の記述・整序・資料読み取りも含む |
| QUIZ-07 | 即時判定 | 回答直後に正解・不正解を表示する |
| QUIZ-08 | 表記ゆれ吸収 | 短答式では前後の空白・全角空白を除いて判定し、登録済み別解も正解扱いにする |
| QUIZ-09 | 解説表示 | 回答後に解説を表示する |
| QUIZ-10 | 進捗表示 | 現在の問題番号と進捗バーを表示する |
| QUIZ-11 | 結果表示 | 正解数、正答率、問題別の振り返りを表示する |
| QUIZ-12 | 回答履歴保存 | クイズ終了時に回答履歴をSupabaseへ保存する |
| QUIZ-13 | 優先復習 | 最新回答が不正解の問題を、間違えた回数と直近の不正解日時をもとに優先出題する |
| QUIZ-14 | ブックマーク | 気になる問題を保存し、保存問題だけを復習できる |

### ダッシュボード

| ID | 機能 | 内容 |
|---|---|---|
| DASH-01 | 総合成績 | 全科目合計の正答率を表示する |
| DASH-02 | 科目別成績 | 科目ごとの正答率を表示する |
| DASH-03 | 復習導線 | 間違えた問題がある場合、優先復習へ進める |
| DASH-04 | 科目詳細導線 | 各科目の詳細ページへ移動する |
| DASH-05 | 学習履歴グラフ | 直近7日間の回答数を棒グラフで表示する |
| DASH-06 | 弱点カテゴリ表示 | 回答履歴から正答率が低いカテゴリを表示する |

## 4. 画面設計

| パス | ページ | 認証 | 内容 |
|---|---|---|---|
| `/` | ランディング | 不要 | アプリ概要、ログイン/登録導線 |
| `/auth/login` | ログイン | 不要 | メールログイン、Googleログイン |
| `/auth/signup` | 新規登録 | 不要 | メール登録、Googleログイン |
| `/auth/callback` | 認証コールバック | 不要 | Supabase Authの戻り先 |
| `/dashboard` | ダッシュボード | 必要 | 学習状況、科目一覧 |
| `/subjects/[subject]` | 科目詳細 | 必要 | 学年別スタート、復習導線 |
| `/quiz/[subject]?grade=1&format=multiple_choice` | 4択クイズ | 必要 | 4択問題をランダム10問出題 |
| `/quiz/[subject]?grade=1&format=short_answer` | 短答式クイズ | 必要 | 短答式問題をランダム10問出題 |
| `/quiz/[subject]?grade=1&format=multiple_choice&review=wrong` | 4択優先復習 | 必要 | 4択の不正解問題を優先度順に解き直す |
| `/quiz/[subject]?grade=1&format=short_answer&review=wrong` | 短答式優先復習 | 必要 | 短答式の不正解問題を優先度順に解き直す |
| `/result` | 結果 | 必要 | 結果サマリー、問題別振り返り |

### 基本フロー

```text
ランディング
  ↓
ログイン / 新規登録
  ↓
ダッシュボード
  ↓
科目詳細
  ↓
通常クイズ or 間違い直し
  ↓
結果
  ↓
再挑戦 / 科目詳細 / ダッシュボード
```

### UI方針

- スマートフォン、タブレット、PCで使えるレスポンシブUIにする
- 学習アプリとして、情報量と操作導線を優先する
- 装飾に頼りすぎず、成績・出題・復習の状態が一目で分かる画面にする
- 主要操作はボタンとして明確に表示する
- 問題文、選択肢、解説は小さい画面でも読みやすくする

## 5. データベース設計

### テーブル

#### `subjects`

科目マスタ。

| カラム | 型 | 説明 |
|---|---|---|
| `id` | uuid | 科目ID |

| `name_en` | text | URL用の英語名 |

#### `problems`

問題データ。

| カラム | 型 | 説明 |
|---|---|---|
| `id` | uuid | 問題ID |
| `subject_id` | uuid | 科目ID |
| `grade` | int | 学年 |
| `exam_term` | text | テスト範囲 |
| `category` | text | 問題カテゴリ |
| `passage` | text | 読解用本文。通常問題ではNULL |
| `question` | text | 問題文 |
| `choice_a` | text | 選択肢A |
| `choice_b` | text | 選択肢B |
| `choice_c` | text | 選択肢C |
| `choice_d` | text | 選択肢D |
| `answer` | char(1) | 正解 |
| `problem_format` | text | 問題形式。`multiple_choice` または `short_answer` |
| `correct_text` | text | 短答式の正答 |
| `accepted_answers` | text[] | 短答式の別解 |
| `explanation` | text | 解説 |
| `difficulty` | int | 難易度。1から3 |
| `created_at` | timestamptz | 作成日時 |

#### `user_answers`

回答履歴。

| カラム | 型 | 説明 |
|---|---|---|
| `id` | uuid | 回答ID |
| `user_id` | uuid | Supabase AuthのユーザーID |
| `problem_id` | uuid | 問題ID |
| `is_correct` | boolean | 正解したかどうか |
| `answered_at` | timestamptz | 回答日時 |

#### `user_bookmarks`

問題ブックマーク。

| カラム | 型 | 説明 |
|---|---|---|
| `id` | uuid | ブックマークID |
| `user_id` | uuid | Supabase AuthのユーザーID |
| `problem_id` | uuid | 問題ID |
| `created_at` | timestamptz | 保存日時 |

### ビュー

| ビュー | 用途 |
|---|---|
| `user_answer_subject_stats` | ダッシュボードで科目別の回答数・正解数を軽量取得する |
| `latest_user_problem_answers` | 問題ごとの最新回答を取得し、間違い直し対象を判定する |
| `problem_grade_stats` | 科目・学年別の問題数を取得する |
| `user_answer_category_stats` | カテゴリ別の回答数・正解数を取得する |
| `user_answer_daily_stats` | 日別の回答数・正解数を取得する |
| `user_problem_review_priority` | 最新回答が不正解の問題を復習優先度付きで取得する |

### 関数

| 関数 | 用途 |
|---|---|
| `get_random_problems(p_subject_id, p_grade, p_limit, p_problem_format)` | 指定した形式の通常クイズ用問題をSupabase側でランダムに最大10問だけ返す |

### インデックス

| インデックス | 用途 |
|---|---|
| `subjects_name_en_key` | URLから科目を引く |
| `problems_subject_grade_term_idx` | 科目・学年・テスト範囲で問題を探す |
| `user_answers_user_id_idx` | ユーザー別履歴取得 |
| `user_answers_problem_id_idx` | 問題別履歴取得 |
| `user_answers_user_answered_idx` | ユーザーの回答履歴を日時順に扱う |
| `user_answers_user_problem_answered_idx` | 問題ごとの最新回答を扱う |
| `user_bookmarks_user_id_idx` | ユーザー別ブックマーク取得 |
| `user_bookmarks_problem_id_idx` | 問題別ブックマーク取得 |

### RLS

| テーブル | 操作 | ルール |
|---|---|---|
| `subjects` | SELECT | 全員参照可能 |
| `problems` | SELECT | 全員参照可能 |

| `user_answers` | INSERT | 自分の回答履歴のみ追加可能 |
| `user_answers` | DELETE | 自分の回答履歴のみ削除可能 |
| `user_bookmarks` | SELECT | 自分のブックマークのみ |
| `user_bookmarks` | INSERT | 自分のブックマークのみ追加可能 |
| `user_bookmarks` | DELETE | 自分のブックマークのみ削除可能 |

## 6. Supabase運用

### 初回セットアップ

Supabase SQL Editorで以下を順番に実行する。

```text
supabase/schema.sql
supabase/seed.sql
```

### schema.sqlを再実行するタイミング

以下を変更した場合は、Vercelへpushするだけでは反映されないため、Supabase SQL Editorで `schema.sql` を再実行する。

- テーブル定義
- RLS
- index
- view
- function
- grant

### seed.sqlを再実行するタイミング

問題データを入れ直したい場合に実行する。

現在の `seed.sql` は `user_answers` と `problems` を削除してから問題を投入するため、本番運用で実行すると回答履歴が消える。公開後に実行する場合は注意する。

## 7. 認証設定

### Supabase

- Emailログインを有効化する
- Googleログインを使う場合はGoogle Providerを有効化する
- Site URLに本番URLを設定する
- Redirect URLにローカルURLと本番URLを登録する

登録URLの例:

```text
http://localhost:3000
https://tyugaku-benkyo.vercel.app
```

### Google Cloud Console

Google OAuthを使う場合は、Google Cloud ConsoleのOAuthクライアントにSupabaseのCallback URLを登録する。

## 8. パフォーマンス方針

### 現在の対応

- ダッシュボードの成績集計はDBビューで取得する
- 科目詳細の問題数は集計ビューで取得する
- 優先復習対象はDBビューで間違えた回数・最新不正解日時をもとに取得する
- 弱点カテゴリと学習履歴はDBビューで集計済みデータを取得する
- 通常クイズはDB関数でランダム10問だけ取得する
- iPhone / iPad / PCでレイアウトが崩れないようにレスポンシブ対応する

### 今後の改善候補

- 認証チェックの重複削減
- Supabase RPCの追加による画面ごとの取得回数削減

## 9. デプロイ運用

### Vercel

- GitHubリポジトリをVercelに連携する
- Environment VariablesにSupabaseの環境変数を設定する
- `main` ブランチへpushすると自動デプロイされる

### 変更反映の流れ

```bash
npm run lint
npm run build
git add .
git commit -m "Update app"
git push
```

DB変更がある場合は、pushとは別にSupabase SQL EditorでSQLを実行する。

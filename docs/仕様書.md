## 1. プロダクト概要

### 目的

定期テストに向けて、中学生が自習できる環境を提供する。科目別・学年別の問題を解くことで、弱点を把握し、効率的な学習を支援する。

### ターゲットユーザー

- 中学1〜3年生（全国共通）
- 定期テスト前後に集中して学習したい生徒

### コンセプト

> 「解く → 確認する → 弱点をなくす」のサイクルを手軽に繰り返せること。

## 2. 技術スタック・環境構成

### フロントエンド

| 項目 | 採用技術 | 理由 |
|---|---|---|
| フレームワーク | **Next.js 16** (App Router) | SSR/SSGの柔軟な選択、Vercelとの親和性 |
| 言語 | **TypeScript** | 型安全性による品質向上 |
| スタイリング | **Tailwind CSS** | 高速なUI開発 |

### バックエンド・インフラ

| 項目 | 採用技術 | 理由 |
|---|---|---|
| APIサーバー | **Next.js API Routes** | フロントと同一リポジトリで管理可能 |
| 認証 | **Supabase Auth** | メール・OAuthを即座に実装可能 |
| データベース | **Supabase (PostgreSQL)** | RLSで行レベルセキュリティを簡潔に実装 |
| ホスティング | **Vercel** | Next.jsとの最高の互換性 |

### ローカル開発環境

```
Node.js: 20.x 以上
npm: 10.x 以上
```

### 環境変数

| 変数名 | 説明 | 必須 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | SupabaseプロジェクトURL | ✅ |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase公開APIキー | ✅ |

## 3. 機能要件一覧

### 3-1. 認証機能

| ID | 機能名 | 内容 |
|---|---|---|
| AUTH-01 | メールアドレス登録 | メール + パスワード（6文字以上）で新規登録。確認メールを送信する |
| AUTH-02 | メールアドレスログイン | メール + パスワードでログイン |
| AUTH-03 | Googleログイン | Supabase OAuth経由でGoogleアカウントでログイン |
| AUTH-04 | ログアウト | セッションを破棄してランディングページへリダイレクト |
| AUTH-05 | 認証ガード | 未ログイン状態でログイン後ページにアクセスした場合、ログインページへリダイレクト |
| AUTH-06 | ログイン済みリダイレクト | ログイン済み状態で認証ページにアクセスした場合、ダッシュボードへリダイレクト |

### 3-2. 科目・問題機能

| ID | 機能名 | 内容 |
|---|---|---|
| SUBJ-01 | 科目一覧表示 | 5科目（国語・数学・英語・理科・社会）をカード形式で表示する |
| SUBJ-02 | 学年選択 | 科目選択後、中1・中2・中3の学年を選択できる |
| SUBJ-03 | 問題シャッフル | 同一科目・学年の問題をランダムな順番で出題する（最大10問） |

### 3-3. クイズ機能

| ID | 機能名 | 内容 |
|---|---|---|
| QUIZ-01 | 4択問題表示 | 問題文と選択肢A〜Dを表示する |
| QUIZ-02 | 難易度表示 | 各問題の難易度を星1〜3で表示する |
| QUIZ-03 | 即時フィードバック | 選択直後に正解/不正解を色で表示する（正解: 緑、不正解: 赤） |
| QUIZ-04 | 解説表示 | 選択後に解説テキストを表示する |
| QUIZ-05 | 進捗バー | 現在何問目かを進捗バーで表示する |
| QUIZ-06 | 次の問題へ遷移 | 選択後に「次の問題へ」ボタンで次問に進む |

### 3-4. 結果・学習記録機能

| ID | 機能名 | 内容 |
|---|---|---|
| RES-01 | 結果サマリー表示 | クイズ終了後に正答率・正解数を表示する |
| RES-02 | 問題別振り返り | 全問題の正解/不正解・正解の選択肢・解説を一覧表示する |
| RES-03 | スコアメッセージ | 正答率に応じた励ましメッセージを表示する |
| RES-04 | 回答履歴の保存 | クイズ終了時、ログイン中ユーザーの回答をDBに保存する |
| RES-05 | 科目別正答率の表示 | ダッシュボードに科目ごとの累計正答率を表示する |
| RES-06 | 総合正答率の表示 | ダッシュボードに全科目合計の正答率を表示する |
| RES-07 | 再挑戦 | 同じ科目・学年でもう一度クイズを開始できる |

## 4. 画面設計・ページ一覧

### ページ一覧

| パス | ページ名 | 認証 | 説明 |
|---|---|---|---|
| `/` | ランディング | 不要 | アプリ紹介・ログイン/登録への誘導 |
| `/auth/login` | ログイン | 不要 | メール/Google でログイン |
| `/auth/signup` | 新規登録 | 不要 | メール/Google で新規登録 |
| `/auth/callback` | コールバック | 不要 | OAuth・メール確認後のリダイレクト先 |
| `/dashboard` | ダッシュボード | **必要** | 科目カード一覧 + 正答率表示 |
| `/subjects/[subject]` | 科目詳細 | **必要** | 学年選択（中1/中2/中3） |
| `/quiz/[subject]` | クイズ | **必要** | 4択問題（?gradeクエリで学年指定） |
| `/result` | 結果 | **必要** | クイズ結果の振り返り |

### 画面フロー

```
ランディング (/)
    ↓ ログイン/新規登録
ログイン (/auth/login) ─── 新規登録 (/auth/signup)
    ↓ 認証成功
ダッシュボード (/dashboard)
    ↓ 科目カードをタップ
科目詳細 (/subjects/[subject])
    ↓ 学年を選択
クイズ (/quiz/[subject]?grade=1)
    ↓ 全問回答
結果 (/result)
    ↓ もう一度 / 別学年 / ダッシュボードへ
```

### 各画面の主要コンテンツ

#### ランディングページ (`/`)

- ヘッダー（ロゴ + ログインボタン）
- キャッチコピー + サブコピー
- 「無料で始める」「ログイン」ボタン
- 特徴カード3枚（5科目対応 / 学年別 / 正答率記録）
- フッター

#### ダッシュボード (`/dashboard`)

- 挨拶テキスト
- 総合正答率カード（1問以上解いた場合のみ表示）
- 科目カード × 5（アイコン・科目名・正答率またはまだ未解答）

#### 科目詳細 (`/subjects/[subject]`)

- 科目アイコン・名前
- 学年別カード × 3（「スタート」ボタン or 問題準備中）
- 難易度の説明

#### クイズ (`/quiz/[subject]`)

- 進捗バー（N / 10 問）
- 問題文カード（難易度の星付き）
- 選択肢ボタン × 4（A〜D）
- 正解後：解説エリア + 「次の問題へ」ボタン

#### 結果 (`/result`)

- スコアカード（正答率 + メッセージ）
- 問題別振り返りリスト
- ボタン：もう一度挑戦 / 別の学年を選ぶ / ダッシュボードへ

## 5. DBスキーマ設計

### ER図（テキスト）

```
subjects ─────────── problems ─────────── user_answers
   │                    │                      │
   │ 1:N               │ 1:N                  │ N:1
   └────────────────────┘                auth.users
                                              │
                                    user_answers.user_id
```

### テーブル定義

#### `subjects`（科目）

| カラム | 型 | 制約 | 説明 |
|---|---|---|---|
| `id` | uuid | PK, default gen_random_uuid() | 科目ID |
| `name` | text | NOT NULL | 科目名（例: 数学） |
| `name_en` | text | NOT NULL | 英語名（例: math）※URLに使用 |
| `icon` | text | NOT NULL | 絵文字アイコン（例: 🔢） |
| `color` | text | NOT NULL | カラーコード（Tailwind用） |

#### `problems`（問題）

| カラム | 型 | 制約 | 説明 |
|---|---|---|---|
| `id` | uuid | PK, default gen_random_uuid() | 問題ID |
| `subject_id` | uuid | FK → subjects.id | 科目ID |
| `grade` | int | NOT NULL, 1〜3 | 学年（1/2/3） |
| `question` | text | NOT NULL | 問題文 |
| `choice_a` | text | NOT NULL | 選択肢A |
| `choice_b` | text | NOT NULL | 選択肢B |
| `choice_c` | text | NOT NULL | 選択肢C |
| `choice_d` | text | NOT NULL | 選択肢D |
| `answer` | char(1) | NOT NULL, A/B/C/D | 正解の選択肢 |
| `explanation` | text | NULL可 | 解説文 |
| `difficulty` | int | default 1, 1〜3 | 難易度（1:基礎 2:標準 3:応用） |
| `created_at` | timestamptz | default now() | 作成日時 |

#### `user_answers`（回答履歴）

| カラム | 型 | 制約 | 説明 |
|---|---|---|---|
| `id` | uuid | PK, default gen_random_uuid() | 回答ID |
| `user_id` | uuid | FK → auth.users.id, ON DELETE CASCADE | ユーザーID |
| `problem_id` | uuid | FK → problems.id, ON DELETE CASCADE | 問題ID |
| `is_correct` | boolean | NOT NULL | 正解かどうか |
| `answered_at` | timestamptz | default now() | 回答日時 |

### Row Level Security（RLS）ポリシー

| テーブル | ポリシー | 内容 |
|---|---|---|
| subjects | SELECT | 全員参照可 |
| problems | SELECT | 全員参照可 |
| user_answers | SELECT | 自分のデータのみ |
| user_answers | INSERT | 自分のデータのみ |
| user_answers | DELETE | 自分のデータのみ |

## 6. 認証フロー

### メール/パスワード登録

```
ユーザー → 登録フォーム入力
    → Supabase: signUp()
    → 確認メール送信
    → メール内リンクをクリック
    → /auth/callback にリダイレクト
    → セッション確立
    → /dashboard へリダイレクト
```

### Googleログイン

```
ユーザー → Googleボタンクリック
    → Supabase: signInWithOAuth({ provider: 'google' })
    → Google認証画面
    → /auth/callback にリダイレクト
    → セッション確立
    → /dashboard へリダイレクト
```

### 認証ガード（proxy.ts）

```
リクエスト
    → セッション確認
    → 未認証 + 保護ルート → /auth/login にリダイレクト
    → 認証済み + 認証ページ → /dashboard にリダイレクト
    → それ以外 → そのまま通過
```

## 7. 非機能要件

| 項目 | 要件 |
|---|---|
| 対応デバイス | スマートフォン・タブレット・PC（レスポンシブ対応） |
| 対応ブラウザ | Chrome / Safari / Firefox 最新版 |
| パフォーマンス | 初回ページ表示 3秒以内（LTE環境） |
| セキュリティ | RLSによる行レベルセキュリティ、環境変数でのキー管理 |
| データ保護 | ユーザーは自分の回答履歴のみ参照・削除可能 |
| 言語 | 日本語のみ |
